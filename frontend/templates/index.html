Isolation Forest Model Architecture & Methodology

Core Algorithm Isolation Forest (sklearn.ensemble.IsolationForest)

Constructs 100 orthogonal isolation trees that partition the feature space with random cuts.

Trained Features Amount, Hour, Frequency (24h), Location Indicator

Features are normalized with StandardScaler and stored in preprocessor.joblib.

Why Unsupervised? No Prior Fraud Labels Needed

Anomalies are detected purely by their low average path length across the decision tree ensemble.

Backend & Persistence Python Flask REST API + SQLite

Inference takes < 5ms; each transaction is automatically logged for regulatory audit trails.
